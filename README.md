## Sobre o projeto

O site foi desenvolvido para centralizar minha presença profissional na internet, apresentando minhas experiências e competências nas áreas de Tecnologia da Informação, infraestrutura de redes, design gráfico e marketing digital.

A página também conecta minha atuação profissional à **RootSys Consultoria**, empresa especializada em soluções de TI para empresas.

### Principais características

- Página pessoal e apresentação profissional.
- Layout responsivo para computadores, tablets e smartphones.
- Interface moderna com tema escuro.
- Navegação por seções.
- Apresentação de serviços e competências.
- Links para redes sociais e canais profissionais.
- Integração com Google Analytics 4.
- Otimização básica para mecanismos de busca (SEO).
- Hospedagem estática com GitHub Pages.

## Hospedagem com GitHub Pages

Este projeto utiliza o GitHub Pages para disponibilizar uma página web estática diretamente a partir de um repositório GitHub.

Por utilizar o formato de repositório especial `usuario.github.io`, a publicação pode ser realizada diretamente no domínio principal do GitHub Pages.

**Endereço publicado:**

https://silvacharles.github.io/

## Personalização

O site utiliza CSS incorporado ao próprio arquivo `index.html`.

As principais configurações visuais estão definidas nas variáveis CSS:

```css
:root {
    --bg-primary: #0a0a0a;
    --bg-secondary: #111111;
    --bg-card: #1a1a1a;
    --text-primary: #ededed;
    --text-secondary: #a1a1a1;
    --accent: #10b981;
    --accent-hover: #059669;
}
```

Essas variáveis permitem personalizar facilmente as cores e a identidade visual da página.
